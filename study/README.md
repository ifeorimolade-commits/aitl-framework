# AITL Corpus Study 1

The first empirical test of the AI-Generated Interface Accessibility Assurance Framework (AIAAF) on interfaces generated by widely used AI tools. It asks how often the eight generative failure patterns (P1 to P8) occur in practice, how many of them conventional automated checkers miss, what the AITL automated layer catches, whether independent evaluators apply the rubric consistently, and what happens when the AITL MCP server is placed in the generation loop.

Start with `PROTOCOL.md`. It was committed and tagged `study1-prereg` before any interface was generated.

| Path | What it is |
|---|---|
| `PROTOCOL.md` | Preregistered design, predictions, analysis plan, limitations, deviations log |
| `CODEBOOK.md` | Operational rules for coding each pattern, scoring each dimension, and the gate |
| `RUNBOOK.md` | The step by step procedure for the study day |
| `prompts/` | The exact prompts, hashed in `data/prompt_sha256.txt` |
| `corpus/source/` | Generated interfaces exactly as the tools returned them, hashed in `data/corpus_sha256.txt` |
| `corpus/rendered/` | The DOM of each interface after it rendered in Chromium |
| `corpus/chat-evidence/` | Screenshots and recordings showing each prompt and response |
| `data/` | Generation log, coding sheets, score sheets, unclassified defects, MCP loop log |
| `results/` | axe-core, Lighthouse and AITL automated outputs, evidence aids, screenshots, and `summary.md` |
| `scripts/` | `audit.mjs`, `lighthouse.mjs`, `mcp_smoke_test.mjs`, `summarize.py` |
| `rater-packet/` | Instructions and sheets for the independent evaluators |
| `mcp-loop/` | Procedure for in the loop sessions, deferred to a later study |
| `pilot/` | The November 4 pipeline dry run on the repository's synthetic sample |

## Reproducing the analysis

```bash
cd mcp-server && npm install && cd ..
cd study/scripts && npm install && npx playwright install chromium && cd ../..
node study/scripts/audit.mjs        # automated layer, evidence aids, screenshots
node study/scripts/lighthouse.mjs   # Lighthouse accessibility scores
python3 study/scripts/summarize.py  # every table in the report
```

Generated output from AI tools varies from run to run, so rerunning the prompts will give different interfaces. Reproducing the analysis means rerunning the scripts on the published corpus.
